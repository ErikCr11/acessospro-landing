# AcessosPro

Landing page responsiva com catálogo de plataformas, provas sociais e convite para a comunidade no WhatsApp.

## Publicar na Vercel

Importe este repositório como um projeto na Vercel. A configuração em `vercel.json` publica a pasta `dist` sem instalação ou etapa de build.

## Arquivos principais

- `dist/index.html`: conteúdo da página
- `dist/acessos.css`: estilos e responsividade
- `dist/acessos.js`: navegação e galeria de clientes
- `dist/assets/`: logos, prints e vídeo

As imagens e marcas mantêm seus respectivos titulares.
